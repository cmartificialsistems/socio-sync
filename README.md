# 🤝 SocioSync - Aplicación de Reuniones, Minutas e Ideas con tu Socio

**SocioSync** es una plataforma web rápida y moderna diseñada específicamente para agendar reuniones diarias entre dos socios, dar seguimiento a los puntos tratados, gestionar tareas pendientes y compartir ideas de negocio con hilos de conversación.

---

## 🚀 Características Incluidas

1. 📅 **Agendamiento y Horario Diario Modificable:**
   - Define tu hora habitual de reunión (ej. 10:00 AM) y duración (ej. 45 min).
   - Enlace permanente a videollamada (Google Meet/Zoom) con botón de acceso directo.
   - Navegador entre reuniones pasadas, actuales y futuras.

2. 📝 **Puntos a Tratar (Agenda):**
   - Agrega temas para discutir en la reunión activa.
   - Clasificación por prioridad (Alta 🔴, Media 🟡, Baja 🟢).
   - Cambio de estado: `Pendiente` ➔ `En Discusión` ➔ `Resuelto`.
   - **Conversión a 1 Clic:** Transforma cualquier punto a tratar directamente en una Tarea Pendiente.

3. ✅ **Puntos a Seguir (Tareas Pendientes):**
   - Compromisos derivados de las reuniones.
   - Asignación a: `Alex (Tú)`, `Carlos (Socio)` o `Ambos`.
   - Fecha límite con alertas visuales para tareas vencidas.
   - Filtros dinámicos por responsable y por estado.

4. 💡 **Banco de Ideas de Negocio:**
   - Muro colaborativo para proponer y clasificar nuevas oportunidades.
   - Sistema de votación / interés entre ambos socios.
   - Botón *"Llevar a Reunión"* para incluir una idea en la agenda activa en 1 clic.

5. 💬 **Hilos de Comentarios Interactivos:**
   - Cada tema, tarea o idea tiene su propio espacio de comentarios en tiempo real.
   - Permite simular/cambiar la perspectiva entre tu usuario y el de tu socio desde la barra superior.

6. 💾 **Persistencia de Datos y Respaldo:**
   - Guarda automáticamente todo en `localStorage`.
   - Opción para exportar copia de seguridad en JSON o restablecer datos demo.

---

## 🛠️ Cómo Ejecutar la Aplicación

La aplicación está ubicada en:
`C:\Users\user\.gemini\antigravity\scratch\socio-sync`

Para iniciar el servidor local de desarrollo:

```bash
cd C:\Users\user\.gemini\antigravity\scratch\socio-sync
npm run dev
```

Abre tu navegador en la URL indicada (usualmente `http://localhost:5173`).
